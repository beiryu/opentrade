OpenTrade: một binary, một file SQLite, một quyết định mỗi phiên

Sơ đồ theo source tại github.com/beiryu/opentrade (10/10/2026). Không có service, queue hay worker nền. Một quyết định là một lời gọi hàm; replay là lời gọi đó trong vòng lặp qua từng phiên lịch sử.

Backend Go 1.26, stdlib net/http, modernc sqlite UI React 19 + Vite, nhúng vào binary License MIT Dòng Go ~3.000 + test

Package

  • rules hàm thuần về luật sàn; indicators SMA/EMA/RSI/ATR tự viết.
  • market Bar, Provider, CSV, sinh dữ liệu tổng hợp theo seed.
  • engine context, prompt, 3 decider, guards, Cycle/Roll/Step/Replay.
  • paper lệnh ngày, lot FIFO có ngày về, tiền chờ về, giữ chỗ tiền.
  • llm client HTTP tương thích OpenAI, JSON mode, retry; Fake cho test.
  • store SQLite 4 bảng; scorecard metrics và verdict; api JSON + SPA nhúng.

Mọi lệnh ra broker chỉ có một đường: qua ApplyGuards rồi Submit. Adapter đặt lệnh thật sau này đứng sau đúng hai cửa đó.
